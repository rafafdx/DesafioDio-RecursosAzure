## 🎯 Objetivo

- Compreender como criar, configurar e dimensionar Máquinas Virtuais (VMs) no Azure;
- Entender os diferentes tipos de SKU disponíveis e suas finalidades;
- Explorar opções de desempenho, custo e escalabilidade.

---

## 📘 O que foi aprendido

Durante o desenvolvimento do laboratório, aprendi a:

- Criar uma máquina virtual no Azure a partir do portal;
- Escolher a imagem correta do sistema operacional;
- Ajustar o tamanho da VM de acordo com a carga e uso estimado;
- Configurar disco, rede, segurança e acesso remoto (RDP/SSH);
- Monitorar e realizar ajustes de performance;
- Estimar custos e simular cenários de dimensionamento.

---

## 🔍 Principais Conceitos

- **SKU (Stock Keeping Unit)**: Diferentes tamanhos e configurações de VM para atender diversos perfis de uso.
- **Dimensionamento Vertical vs. Horizontal**:
  - Vertical: aumentar capacidade de uma VM.
  - Horizontal: adicionar múltiplas VMs e distribuir a carga.
- **Disco gerenciado vs. não gerenciado**.
- **Grupo de Recursos (Resource Group)**: agrupamento lógico de recursos do Azure.

---

## ✅ Boas Práticas

- Sempre avaliar o uso real da VM antes de escalar;
- Monitorar recursos com Azure Monitor e Advisor;
- Utilizar tags para organização e controle de custos;
- Evitar deixar VMs ligadas sem uso (geram cobrança contínua).
